## BlendKeep v0.1.0（初版）

Blender の `.blend` を、**保存するたびに自動で履歴に残す** Windows 常駐ツールです。アドオンは要りません。

### できること
- 指定したフォルダ（複数・複数ドライブ可）を見張り、保存が終わったら履歴を作る
- 履歴をサムネイル付きで一覧し、1クリックで取り出す（既存のファイルは上書きしません）
- 履歴へのメモ（メモ付きは自動で削除されません）、複数選択での削除
- **小さい履歴**: 圧縮に加え、1MB 以上のファイルは変わった部分だけ保存（差分保存）。
  16MB のシーンを8回保存して、合計 129.6MB → 7.1MB（Blender 5.2.2 で実測）
- **レンダー完了通知**（トレイ / 任意で Discord）。設定画面の「Blender に導入する」で、小さなスクリプトを Blender の起動フォルダに置きます（アドオンの有効化は不要。導入後、Blender を再起動）
- Windows ログイン時の自動開始、二重起動の防止、履歴の保存先の変更

### 使い方
1. `BlendKeep-v0.1.0-windows.zip` をダウンロードして展開する
2. `BlendKeep\BlendKeep.exe` を実行する（インストール不要）
3. 最初に開く設定画面で、Blender のプロジェクトのフォルダを追加する

ダウンロードの確認: 同じ場所の `.sha256` と、PowerShell の `Get-FileHash BlendKeep-v0.1.0-windows.zip` の結果を比べてください。

### 知っておいてほしいこと
- **コード署名をしていません。** 初回に Windows の SmartScreen が「PC が保護されました」と出すことがあります（「詳細情報」→「実行」）。
- 動作確認は、Windows の実機と、Blender 5.2.2 で行いました。ほかのバージョンの Blender では、履歴の作成は動くはずですが、確かめていません。
- 開発初期です。不具合や要望は Issues へ。

### English
First release. A Windows tray app that keeps a version history of your `.blend` files every time you save — no Blender add-on needed.
Thumbnail browser, safe restore, notes, delta storage (8 saves of a 16 MB scene = 7 MB), and render-finished notifications (tray / Discord).
Unzip `BlendKeep-v0.1.0-windows.zip` and run `BlendKeep.exe`. Not code-signed yet, so SmartScreen may warn. Verify with the `.sha256` file.
